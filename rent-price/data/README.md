# Данные

Файлов конкурса здесь нет намеренно: данные принадлежат организаторам, и выкладывать
их в публичный репозиторий не стоит. Они добавлены в `.gitignore`.

Скачайте архив с [aiijc.com](https://aiijc.com/ru/) и положите в эту папку три файла:

```
data/
  train
  test
  sample_submission
```

Расширения не нужны — внутри это обычные CSV, и код читает оба варианта
(`train` и `train.csv`).

## Что внутри

| Поле | Тип | Диапазон | Комментарий |
|---|---|---|---|
| `id` | int | 0–8999 | train 0–6999, test 7000–8999 |
| `area` | float, м² | 18.0–260.0 | обрезана с двух сторон |
| `district` | категория | 10 значений | главный предиктор |
| `floor` | int | 1–40 | влияние слабое |
| `distance_to_center` | float, км | 0.20–21.51 | цена падает экспоненциально |
| `rent_price` | float | 350–66217 | таргет, обрезан снизу на 350 |

7000 строк в train, 2000 в test. Пропусков и дубликатов нет.
