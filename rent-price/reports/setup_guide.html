01

Что я могу с вашим репозиторием, а что нет

Отвечаю прямо, потому что от этого зависит вся дальнейшая схема работы: вести репозиторий я могу, а отправлять в него коммиты сам — нет.

✓Могу

  • Писать и переписывать код, ноутбуки, README, документацию
  • Готовить изменения целиком — с текстом коммита, который останется только подтвердить
  • Читать ваш репозиторий напрямую — он публичный, так что актуальное состояние кода я вижу сам
  • Ревьюить ваши изменения, искать ошибки, предлагать структуру
  • Собирать релизы: обновлённые сабмиты, отчёты, графики

✕Не могу

  • Делать git push от вашего имени
  • Создавать за вас ветки и pull request'ы на GitHub
  • Удалять или переименовывать что-либо в репозитории

Причина одна: всё это требует вашего токена доступа к GitHub. Чужие токены и пароли я в работу не беру — это правило, а не техническое ограничение, и обойти его нельзя.

Как это выглядит на практике

Разница между «я пушу» и «пушите вы» — примерно один клик. Я отдаю готовые файлы и текст коммита, вы нажимаете Commit and Push в PyCharm. Авторство коммитов при этом остаётся вашим, что для конкурсной работы даже правильнее.

02

Репозиторий публичный — что это значит

Адрес: github.com/Voldemurik/AI-Challenge-by-Sber-1. Раз он открытый, я клонирую его сам и вижу актуальное состояние кода — спрашивать вас, что там сейчас лежит, больше не нужно.

Одна оговорка

Правила соревнований иногда запрещают публиковать решения до конца этапа: открытый репозиторий формально доступен другим участникам. Спросите об этом поддержку вместе с вопросом про метрику. Если окажется, что нельзя, — в настройках репозитория есть переключатель Settings → Danger Zone → Change visibility, одна кнопка. Работать мы сможем и с приватным, просто вы будете класть файлы в папку проекта, как делали до сих пор.

Пока правила не проверены, есть промежуточный вариант: выложить структуру, код и README, а ноутбук с полным разбором и готовые сабмиты добавить после 15 сентября. Скажите, если хотите так — соберу отдельный архив.

03

Что установить

Судя по папкам PycharmProjects и PythonProject у вас на компьютере, первые два пункта уже закрыты — проверьте и переходите к третьему.

Python 3.10 или новее

Проверить: откройте Пуск → cmd и выполните команду. Если версия ниже 3.10 или команда не найдена — скачайте с python.org.

python --version

При установке обязательно поставьте галочку «Add python.exe to PATH» — без неё команда python не заработает в консоли.

PyCharm Community Edition

Бесплатная версия, её достаточно. В ней уже встроены и Git, и поддержка Jupyter-ноутбуков, так что отдельные программы для этого не нужны. Скачать: jetbrains.com/pycharm.

Если привычнее VS Code — тоже подойдёт, поставьте расширения Python и Jupyter.

Git for Windows

Нужен, даже если работать через кнопки PyCharm: PyCharm вызывает его под капотом. Скачать: git-scm.com. Все настройки при установке оставляйте по умолчанию.

git --version

Аккаунт на GitHub

Регистрация на github.com — почта, имя пользователя, пароль. Включите двухфакторную аутентификацию, когда предложат: без неё GitHub со временем начнёт ограничивать аккаунт.

Имя пользователя стоит выбрать нейтральное — этот аккаунт вполне может пригодиться при поступлении и на первой работе.

04

Первый запуск

Архив AI-Challenge-by-Sber-1.zip уже лежит в папке проекта. Внутри — содержимое репозитория: код, ноутбук, README, отчёты, .gitignore и оба сабмита. Файлов конкурса в архиве нет намеренно — их вы добавите на четвёртом шаге.

Распакуйте архив

Не в папку конкурса, а туда, где вы держите проекты — например, в C:\Users\...\PycharmProjects\. Получится папка AI-Challenge-by-Sber-1, а внутри неё rent-price — рабочая папка этой задачи.

Задача аренды лежит в подпапке специально: когда возьмётесь за две другие темы квалификации, они станут соседними папками в том же репозитории.

Откройте в PyCharm папку rent-price

File → Open и выберите именно rent-price, а не корень репозитория — тогда PyCharm правильно подхватит пути к данным и модулям.

Создайте виртуальное окружение

PyCharm обычно предлагает это сам во всплывающем окне — согласитесь. Если не предложил: File → Settings → Project → Python Interpreter → Add Interpreter → Add Local Interpreter → Virtualenv, тип .venv.

Виртуальное окружение — отдельная папка с библиотеками только для этого проекта. Нужна, чтобы установка чего-нибудь для одного проекта не ломала другой.

Положите данные конкурса

Скопируйте train, test и sample_submission из папки конкурса в rent-price/data/. Переименовывать не нужно — код читает и с расширением .csv, и без него.

Установите библиотеки

Откройте в PyCharm вкладку Terminal внизу и выполните:

pip install -r requirements.txt

Займёт пару минут. Если pip ругается на права — добавьте --user.

Проверьте, что всё работает

В том же терминале:

python scripts/make_submission.py

Скрипт напечатает проверку данных, таблицу кросс-валидации и пересоберёт два файла в submissions/. Если увидели строку deg 3, mean · RMSE 1266.459 — всё встало правильно.

Откройте ноутбук

Файл notebooks/01_solution.ipynb — двойной клик в PyCharm. Там весь разбор с графиками. Запустить все ячейки: Run All вверху.

Если Python ставить не хочется — те же материалы лежат в reports/ обычными HTML-файлами, они открываются в браузере.

05

Загрузить проект в репозиторий

Репозиторий уже создан и пока содержит только README. Архив AI-Challenge-by-Sber-1.zip лежит в папке проекта — внутри ровно те 18 файлов, которые должны туда попасть. Данных конкурса в архиве намеренно нет.

Есть два пути. Первый — быстрее, второй — правильнее на будущее.

Через сайт GitHub — 2 минуты

Ничего устанавливать не нужно, годится прямо сейчас.

  • Распакуйте архив
  • Откройте репозиторий на github.com
  • Add file → Upload files
  • Перетащите в окно браузера содержимое папки AI-Challenge-by-Sber-1 — сами файлы и папку rent-price, а не папку целиком
  • Внизу впишите описание коммита и нажмите Commit changes

На вопрос о замене README.md отвечайте согласием — новый содержательнее.

Через PyCharm — правильный путь

Так вы будете работать дальше, поэтому настроить стоит один раз.

  • File → Project from Version Control, вставьте адрес репозитория
  • Скопируйте в открывшуюся папку содержимое архива, поверх существующего
  • Положите train, test, sample_submission в rent-price/data/
  • Вкладка Commit слева — посмотрите список изменений
  • Ctrl+K — описание коммита, Ctrl+Shift+K — отправить

Аккаунт GitHub привязывается один раз: Settings → Version Control → GitHub → Log In via GitHub.

Текст первого коммита

Решение задачи «Стоимость аренды квартиры»: модель, ноутбук, отчёты

Что не должно попасть в репозиторий

Файлы train, test, sample_submission — они принадлежат организаторам. И папка .venv — она весит сотни мегабайт и восстанавливается одной командой. Оба случая закрыты файлом .gitignore, но при загрузке через сайт .gitignore не действует — там следите сами. Поэтому данных в архиве и нет.

06

Как мы работаем дальше

Шаг 1 — вы

Говорите, что нужно

«Добавь взвешивание по районам», «перепиши README», «проверь, нет ли ошибки в подсчёте метрики», «метрика оказалась MAE — переделай сабмит».

Шаг 2 — я

Готовлю изменения

Сначала клонирую репозиторий и смотрю, что там сейчас — раз он публичный, спрашивать вас не нужно. Потом пишу код, прогоняю кросс-валидацию, проверяю, что ничего не сломалось, и кладу готовые файлы в папку проекта вместе с текстом коммита.

Шаг 3 — вы

Переносите и отправляете

Копируете файлы в папку репозитория поверх старых, в PyCharm смотрите вкладку Commit — там видно построчно, что изменилось, — и жмёте Commit and Push. После этого я снова вижу актуальную версию.

Важно

Смотрите на diff перед отправкой

Это не формальность. Вкладка Commit показывает каждую изменённую строку — привычка их просматривать защищает от чужих ошибок, включая мои, и на защите вы будете понимать каждую строчку своего проекта.
