# Стоимость аренды квартиры — AI Challenge 2026

Решение задачи квалификационного этапа [AI Challenge](https://aiijc.com/ru/): по площади,
району, этажу и удалённости от центра предсказать месячную арендную ставку.

**Метрика — MAE.** Балл считается как `max(0, 1 - MAE / 1500)`: при MAE выше 1500 участник
получает ноль и не проходит этап. Каждые 15 единиц MAE — это 0.01 балла.

## Результат

**MAE ≈ 773.5 на кросс-валидации, что даёт балл ≈ 0.484.**

| Модель | MAE | балл | RMSE | R² |
|---|---:|---:|---:|---:|
| **Медианная регрессия deg 3 + бустинг 0.15** | **773.5** | **0.484** | 1280 | 0.825 |
| Медианная регрессия deg 3 | 775.5 | 0.483 | 1275 | 0.826 |
| МНК в логах + медиана, deg 3 | 780.3 | 0.480 | 1275 | 0.826 |
| МНК в логах, deg 3 (условное среднее) | 795.2 | 0.470 | 1266 | 0.827 |
| LightGBM по log-таргету | 806.4 | 0.462 | 1405 | 0.790 |
| Random Forest | 810.6 | 0.460 | 1392 | 0.793 |
| Медиана по району | 898.5 | 0.401 | 1838 | 0.643 |
| Константа (baseline организаторов) | 1509.8 | 0.008 | 3066 | 0.000 |

Кросс-валидация: 5 фолдов × 4 повтора, `random_state=7`, предсказания клипаются снизу на 350.

**Неустранимый минимум MAE ≈ 754** — столько ошибалась бы модель, знающая истинную формулу
наизусть. Запас на улучшения — около 20 единиц MAE, то есть 0.013 балла.

## Как устроены данные

Данные оказались синтетическими, и порождающую их формулу удалось восстановить:

```
rent_price = base(district) × area^α(district) × exp(−β(district) × distance)
             × (1 + γ × log(1 + floor)) × ε,      log ε ~ N(0, σ_district)
```

Затем цена обрезается снизу на 350.

Ключевое наблюдение: **эластичность по площади α своя у каждого района** — от +1.02 в
`luxury_hills` (цена пропорциональна метражу) до −0.26 в `university` (большие квартиры дешевле).
Модель без взаимодействия `district × log(area)` упирается в MAE ≈ 848; с ним — 795.

## Что дало результат

Три решения, каждое из которых опирается на разбор данных, а не на перебор:

1. **Взаимодействие `district × log(area)`** — основной скачок качества (848 → 795 MAE).
2. **Предсказание медианы, а не среднего.** Метрика MAE минимизируется условной медианой.
   Модель живёт в логарифмах: `exp(μ)` — медиана цены, `exp(μ + σ²/2)` — среднее.
   Достаточно перестать добавлять поправку (795 → 780).
3. **Медианная регрессия вместо МНК.** Остатки в логарифмах скошены влево из-за обрезки цены
   снизу, поэтому среднее и медиана логарифма расходятся. Минимизация суммы модулей вместо
   суммы квадратов убирает смещение (780 → 775). Парный t-тест по 20 фолдам: p = 5.9·10⁻⁴.

Плюс 15 % LightGBM с потерей `l1` в смеси — ещё 2 единицы MAE (775 → 773.5).

Отдельный результат: **градиентный бустинг проигрывает линейной модели.** Зависимость гладкая
и параметрическая, а шума много — деревья аппроксимируют плавные кривые ступеньками и заодно
запоминают шум.

## Структура

```
data/                     данные (в git не хранятся — см. data/README.md)
notebooks/
  01_solution.ipynb       полный разбор: EDA, восстановление формулы, бенчмарк, выводы
src/
  data.py                 загрузка и проверка данных
  model.py                признаки, медианная регрессия, предсказание
  boosting.py             LightGBM с потерей l1 для смеси
  evaluate.py             кросс-валидация, метрики, перевод MAE в баллы
scripts/
  make_submission.py      собрать сабмит одной командой
reports/
  01_solution.html        тот же ноутбук в HTML — открывается без Python
  task_analysis.html      разбор задачи: идеи, риски, план, ресурсы
```

Отчёты в `reports/` — обычные HTML-файлы: скачайте и откройте в браузере, Python не нужен.

## Быстрый старт

```bash
git clone https://github.com/Voldemurik/AI-Challenge-by-Sber-1.git
cd AI-Challenge-by-Sber-1/rent-price

python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux

pip install -r requirements.txt
```

Положите файлы `train`, `test`, `sample_submission` из архива конкурса в `data/`, затем:

```bash
python scripts/make_submission.py
```

Скрипт напечатает кросс-валидацию с баллами и пересоберёт файлы в `submissions/`.
На проверку отправляется **`submissions/submission_mae.csv`**.

Полный разбор с графиками — в `notebooks/01_solution.ipynb`:

```bash
jupyter lab
```
