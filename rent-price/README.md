# Стоимость аренды квартиры — AI Challenge 2026

Решение задачи квалификационного этапа [AI Challenge](https://aiijc.com/ru/): по площади,
району, этажу и удалённости от центра предсказать месячную арендную ставку.

## Главный результат

Данные оказались синтетическими, и порождающую их формулу удалось восстановить. Из-за этого
задача решается не градиентным бустингом, как обычно бывает с табличными данными, а компактной
параметрической моделью — и та обходит LightGBM примерно на 10 % по RMSE.

| Модель | RMSE | MAE | R² |
|---|---:|---:|---:|
| **Блочная лог-линейная (deg 3)** | **1266** | **795** | **0.827** |
| Random Forest | 1392 | 811 | 0.793 |
| LightGBM по log-таргету | 1400 | 801 | 0.792 |
| Ridge на one-hot | 1642 | 848 | 0.715 |
| Константа (sample_submission) | 3066 | 1510 | 0.000 |

Кросс-валидация: 5 фолдов × 4 повтора, `random_state=7`, предсказания клипаются снизу на 350.

Теоретический потолок качества — R² ≈ 0.847: шум в данных мультипликативный, σ ≈ 0.36 в
логарифмах. Модель отстаёт от него на 0.02, то есть выжимать дальше почти нечего.

## Как устроены данные

```
rent_price = base(district) × area^α(district) × exp(−β(district) × distance)
             × (1 + γ × log(1 + floor)) × ε,      log ε ~ N(0, σ_district)
```

Затем цена обрезается снизу на 350.

Ключевое наблюдение: **эластичность по площади α своя у каждого района** — от +1.02 в
`luxury_hills` (цена пропорциональна метражу) до −0.26 в `university` (большие квартиры дешевле).
Модель без взаимодействия `district × log(area)` упирается в R² ≈ 0.72; с ним — 0.83.

## Быстрый старт

```bash
git clone https://github.com/Voldemurik/AI-Challenge-by-Sber-1.git
cd AI-Challenge-by-Sber-1/rent-price

python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

Положите файлы `train`, `test`, `sample_submission` из архива конкурса в `data/`, затем:

```bash
python scripts/make_submission.py
```

Скрипт напечатает кросс-валидацию и создаст два файла в `submissions/`:

- `submission_rmse.csv` — предсказание условного среднего, оптимально для RMSE и R²
- `submission_mae.csv` — предсказание условной медианы, оптимально для MAE и MAPE

Какой отправлять, зависит от метрики лидерборда.

Полный разбор с графиками — в `notebooks/01_solution.ipynb`:

```bash
jupyter lab
```

## Почему среднее и медиана — разные файлы

Модель обучается в логарифмах и возвращает μ — оценку логарифма цены. При обратном переходе
`exp(μ)` даёт **медиану** распределения цены, а `exp(μ + σ²/2)` — **среднее**. Для метрик,
основанных на квадрате ошибки (RMSE, R²), оптимально среднее; для метрик на модуле ошибки
(MAE, MAPE) — медиана. Разница — около 15 пунктов MAE, и достаётся она бесплатно.
