## Стоимость аренды квартиры

По площади, району, этажу и удалённости от центра предсказать месячную арендную ставку.
7000 объектов в обучающей выборке, 2000 в тестовой. Метрика — MAE, балл считается как
`max(0, 1 - MAE / 1500)`.

**Главный результат:** данные оказались синтетическими, и порождающую их формулу удалось
восстановить. Из-за этого задача решается не градиентным бустингом, как обычно бывает с
табличными данными, а компактной параметрической моделью — и та обходит LightGBM
примерно на 4 % по MAE.

| Модель | MAE | балл | R² |
|---|---:|---:|---:|
| **Медианная регрессия deg 3 + бустинг 0.15** | **773.5** | **0.484** | 0.825 |
| Медианная регрессия deg 3 | 775.5 | 0.483 | 0.826 |
| LightGBM по log-таргету | 806.4 | 0.462 | 0.790 |
| Random Forest | 810.6 | 0.460 | 0.793 |
| Константа (baseline организаторов) | 1509.8 | 0.008 | 0.000 |

Неустранимый минимум MAE при таком уровне шума — около 754, то есть выжимать дальше
почти нечего: запас на улучшения — 0.013 балла.

Подробности, графики и разбор — в [`rent-price/README.md`](rent-price/README.md) и
[`rent-price/notebooks/01_solution.ipynb`](rent-price/notebooks/01_solution.ipynb).

## Как запустить

```bash
git clone https://github.com/Voldemurik/AI-Challenge-by-Sber-1.git
cd AI-Challenge-by-Sber-1/rent-price

python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux

pip install -r requirements.txt
python scripts/make_submission.py
```

На проверку отправляется `rent-price/submissions/submission_mae.csv`.

Данные конкурса в репозитории не хранятся — положите `train`, `test` и `sample_submission`
в папку `rent-price/data/`. Подробности в [`rent-price/data/README.md`](rent-price/data/README.md).
